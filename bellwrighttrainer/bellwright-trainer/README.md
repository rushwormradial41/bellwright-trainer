# Bellwright Trainer

A memory trainer for the game Bellwright, providing features like unlimited health, stamina, and resources.

## Features
- Unlimited Health
- Unlimited Stamina
- Unlimited Resources (Wood, Stone, Food)
- Speed Hack
- No Fall Damage

## Usage
Run the trainer as administrator. Select the Bellwright process from the dropdown and activate cheats.

## Build
```
dotnet build
```

## Test
```
dotnet test
```

## Dependencies
- .NET 8.0
- Memory.dll (NuGet)
